🎮 Getting Started

🕹️ Games

The website provides classroom review games designed to help teachers make vocabulary, grammar, speaking, and lesson review more engaging.

Each game has its own rules and reward system. You can read the game's How to Play section before starting.

Yes. The games are designed primarily for classroom team play. The number of teams depends on the individual game. Check the game's help section for specific rules.

The games are designed to be adaptable to different lessons. You can create lesson packs using your own questions, vocabulary, grammar, and other lesson content.

The games are primarily designed for teacher-led classroom activities. The teacher controls the game while students answer questions and make decisions as teams.

📚 Lesson Packs

A lesson pack is a collection of questions and lesson content prepared for use with a game. Instead of entering your questions every time you play, you can prepare a lesson pack and load it when you need it.

Yes. Games that support lesson packs provide a Create Lesson Pack option. This allows you to prepare content specifically for your class and lesson.

Yes. Once you have created a lesson pack, you can load it again when you want to use the same lesson content.

💻 Technical Questions

The games are designed to run through your web browser, so there is no traditional desktop application that needs to be installed.

A modern browser such as Chrome, Edge, Firefox, or Safari should work. Keeping your browser updated is recommended.

🔧 Troubleshooting

First, try refreshing the page. If the problem continues, check your internet connection and try opening the game again. If the issue still occurs, please contact us and tell us which game you were trying to use.
