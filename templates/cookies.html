Cookie Policy

How Teachers Online uses cookies and similar technologies.

This policy describes cookie use identified in the current Teachers Online application. Hosting, security, and other service providers may use additional technologies that depend on their configuration.
Download Cookie Policy (PDF)

Cookies are small pieces of data that a website can store in your browser. This policy explains the cookies and related technologies used when you visit or use Teachers Online.

Teachers Online uses a Flask session cookie for essential website functions. It can maintain a signed-in session and support features such as security checks and temporary messages. The cookie may contain session values such as an account identifier or a security token.

The session cookie is configured with the Secure, HttpOnly, and SameSite=Lax attributes. Flask signs the session data to help detect changes; signing does not encrypt it.

The application does not set a permanent session lifetime, so the cookie is intended to expire when the browser session ends. Browser behavior such as restoring a previous session can affect when session cookies are removed.

A cookie is not necessarily sent to every visitor. The browser receives or updates it when the application changes session data, for example when signing in, storing a temporary notice, or creating a settings security token.

The current application code does not include Google Analytics or an advertising cookie system. Resend email open and click tracking are also reported as disabled in the settings reviewed for the Privacy Policy.

Some pages load resources such as fonts, stylesheets, and JavaScript libraries from third-party services, including Google Fonts and content delivery networks. Loading these resources can send technical information, such as your IP address and browser request details, to the provider. The application code review has not confirmed whether those providers or hosting and security services use additional cookies or similar technologies in connection with your visit.

For details about personal information and service providers, read our Privacy Policy.

You can use your browser settings to view, delete, or block cookies. If you block session cookies, sign-in and some features that rely on session security or temporary messages may not work correctly.

Teachers Online does not currently provide an on-site cookie preference or consent banner.

We may update this page when our cookie use, services, or legal obligations change. The latest version will be published here.

If you have questions about cookies or privacy, contact officialteachersonline@gmail.com. For more information about personal information, see the Privacy Policy.
